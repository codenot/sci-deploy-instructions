01 / THE ROUTE

你购买的不是一个地点，而是一条路径

“东京 VPS”只说明服务器大致放在东京，不能说明中国电信、联通和移动会怎样到达它。

一次访问要先从家庭宽带进入接入网、城域网和国内骨干，再经获批的国际通信业务出入口交给国际传输网，越过海缆或陆缆，到达境外运营商和 VPS 所在网络。回程则由 VPS 一侧重新选路。

  1. 你的宽带电信 / 联通 / 移动
  2. 国内骨干省网与全国骨干
  3. 国际出入口业务出口与传输网
  4. 海外网络Transit / Peer / IX
  5. VPS 网络机房与 Origin AS

路径中每一段都可能由不同公司提供。BGP 负责在自治系统之间传播路由，但它优先表达商业关系和运营策略，并不会自动寻找地图上最短、延迟最低的路线。

先记住两个方向：从你家到 VPS 叫去程，从 VPS 返回你家叫回程。两者由两侧网络分别决策，出现“去程直连、回程绕路”完全正常。

02 / DETOURS

普通国际线路为什么会绕路？

互联网中的“普通线路”通常是价格优先的 Transit 组合。它能保证全球可达，却不承诺中国方向最短，也不承诺晚高峰有足够余量。

绕路通常不是“故障”，而是选路结果

VPS 厂商会从若干上游购买网络。如果其中一个上游价格更低、路由优先级更高，或与中国运营商在本地没有合适互联，数据就可能先被送到另一个区域交接。香港服务器绕日本、新加坡，甚至绕美国再回中国，技术上都可能发生。

此外，物理上存在直达海缆，不等于公共互联网一定使用它。运营商还会根据合同、容量、故障保护、流量工程和出口负载调度。同一条 AS Path 不变时，底层承载的海缆也可能已经切换。

原因一上游便宜但中国互联弱

全球 Transit 足以“能访问”，却可能在远处才与中国运营商交接。

原因二近端 Peer 容量不足

路由看似短，晚高峰却因互联口或下游超售而拥塞。

原因三去回程策略不同

厂商展示的单向 traceroute 不能代表另一方向。

原因四目的前缀不同

同一运营商、同一城市，不同 IP 段也可能选择不同入口。

03 / PREMIUM NETWORKS

精品网真正解决的，是“可控性”

精品网不是让数据违反物理规律变快，而是用更贵的网络产品，换取更直接的中国入口、较充足的互联容量、明确的流量工程，有时还包括合同 SLA。

这类线路的价值在晚高峰最明显：普通线路可能因为共享互联拥塞而丢包、抖动、单线程速度下降；精品承载通常会把流量放在负载较低、策略更稳定的网络中。对于远程桌面、SSH、实时语音、游戏中转和稳定下载，这种差异往往比 CPU 型号更有体感。

比较维度普通国际线路中国方向精品线路
核心目标以成本可控实现全球可达改善特定运营商和地区的路径与稳定性
路由可能绕行其他国家或洲通常选择更直接的境外 PoP 与中国入口
高峰体验更依赖共享互联容量与厂商超售程度一般更稳定，但仍可能因故障或超售退化
价格低，常见大带宽和大流量高，常伴随较小带宽或较贵流量
能否只看名称不能同样不能，必须验证路径、方向和合同等级

精品网不等于专属海缆。CN2、联通 9929、CMIN2 等首先是 ASN、承载网络或商业产品语境。它们可以使用运营商自有、联盟持有或租用的海缆容量，和某一条海缆不存在永久一一对应。

04 / THREE CARRIERS

“三网优化”其实是三个独立问题

电信、联通、移动拥有各自的公众骨干、精品或承载网络及国际网络。每个 ASN 都是独立自治系统，能够配置自己的 BGP 邻接和策略；同集团关系不代表固定串联。

中国电信

  • 电信 163 · AS4134公众骨干，普通国际路由常见；高峰口碑取决于互联和容量。
  • CN2 · AS4809下一代承载网络；经过 CN2 不自动等于 GIA。
  • CTGNet · AS23764中国电信国际运营的全球网络之一，不是前两者唯一出口。

中国联通

  • 联通 169 · AS4837公众互联网骨干，普通线路中常有不错的性价比。
  • 联通 9929 · AS9929业内也称 A 网或联通精品网，常用于更可控的跨境承载。
  • CUG · AS10099联通国际网络；出现 CUG 不自动证明大陆段使用 9929。

中国移动

  • CMNET · AS9808移动大陆公众骨干，自治系统层面独立。
  • CMI · AS58453移动国际全球 IP 网络，香港等亚太方向十分常见。
  • CMIN2 · AS58807另一张国际网络，常作为移动方向精品线路；不能与 CMI 混写。

移动体系有一点特殊：截至资料查询日期，IPinfo 只把 CMI 和 CMIN2 识别为 CMNET 的完整互联网 Transit 上游。这说明移动当前观测到的国际上游更集中在集团内部，但不代表 CMNET 是“子 ASN”，也不是 BGP 协议永久规定的父子关系。

因此，真正的“三网优化”必须回答三个问题：电信回程落在电信 163 还是 CN2？联通回程落在联通 169 还是联通 9929？移动回程使用普通 CMI 还是 CMIN2？如果厂商只展示其中一网，或者只展示去程，就不足以证明三网优化。

05 / MARKETING TRANSLATOR

把 VPS 厂商的宣传词翻译成人话

“国际线路”通常只代表全球可达

它没有承诺中国直连、低拥塞或三网一致。几乎所有公网 VPS 都可以这样描述。

“三网优化”要求看三份独立证据

分别检查电信、联通、移动的去程、回程和晚高峰，而不是只看一个测试 IP。

“CN2 线路”不一定是 CN2 GIA

AS Path 出现 AS4809 或 traceroute 出现 59.43.*，不能单独证明合同产品等级。

“BGP 线路”只说明可以动态选路

BGP 不是高质量的同义词；选路可能更灵活，也可能只是把多条廉价 Transit 混在一起。

“大陆直连”必须补齐方向与运营商

应追问哪一网、哪个方向、哪个 IP 段、在哪个境外 PoP 交接，以及高峰是否保持。

“原生 IP”与线路质量不是一回事

IP 的注册或内容平台识别属性，不能证明路由直、延迟低或晚高峰稳定。

最危险的截图：只展示白天、单一运营商、单一方向、ICMP traceroute，并据此声称“三网精品”。这种材料最多证明当时一条路径可见。

06 / REGIONS

地区怎么选：先看运营商，再看城市

下面是大众常见体验的概括，不是 SLA。实际结果会随省份、前缀、上下游、时段和方向变化。

地区普通线路常见特征对大陆较友好的网络线索购买提醒
中国香港物理距离最近，但 Cogent、GTT 等普通 Transit 仍可能绕日本、新加坡或美西。CMI / CMIN2、CUG、PCCW、Telstra、HGC；分别核对三网。低价热门线路晚高峰易拥塞；“香港”本身不等于低延迟。
日本线路资源丰富；不同骨干对三网差异明显。SoftBank 对中国整体口碑较好；IIJ 常较均衡；NTT、KDDI 对特定网络组合也不错。NTT 到电信 163 热门互联有高峰拥塞口碑；移动可能经香港。
韩国地理近，但国际互联容量通常不如香港、日本充裕。KT、SK Broadband、LG U+；CN2、联通 9929 组合常见较好体验。移动可能绕香港，晚高峰抖动更值得测。
新加坡区域枢纽，但到大陆绕香港、日本甚至美西并不少见。Singtel、Telstra、Tata；联通方向常比电信更友好，移动关注 CMI。服务器城市比不上游网络更能解释体验。
中国台湾延迟通常低，三网一致性不如地理距离看起来那么简单。HiNet、TWGate 通常对电信和移动较直接。联通方向更依赖具体入口和回程。
中国澳门距离近、市场小，同一运营商不同产品差异可能很大。CTM 优化产品、China Telecom Macau 的 CN2 / CTGNet 路径。普通国际产品仍可能绕行；先要测试 IP。
美国西海岸跨太平洋资源多，基础 RTT 高于东亚；廉价大带宽选择多。HE 对联通 169 常有性价比；精品产品关注 CN2、9929、CMI/CMIN2 接入。“洛杉矶”不保证中国直连，机房网络和上游比城市名重要。
欧洲物理时延高，普通线路可能绕美；优化主要是减少绕行和拥塞。联通 9929 常有较稳定组合；Arelion、Cogent、RETN 等表现取决于中国落地。任何宣传都无法把欧洲 RTT 变成东亚水平。

网络名称只是排查线索，不构成厂商或产品推荐。即便同一 ASN，不同机房、不同下游和不同 IP 前缀也会有不同策略。

07 / BUYER CHECKLIST

购买前，按这七步验证

  1. 先问清使用场景

    网页、下载能容忍抖动；SSH、远程桌面、游戏、语音更依赖低抖动和稳定单线程。场景不同，预算应放在不同地方。

  2. 索要测试 IP 和 Looking Glass

    没有可公开测试的目标，就无法确认 Origin AS、上游、路由和高峰表现。仅看商家截图不够。

  3. 分别测试电信、联通、移动

    至少选择与你真实用户同省或邻近区域的三个探测点。不要用某一网的结果代替“三网”。

  4. 同时看去程和回程

    本地 traceroute 主要观察去程；回程要用服务器 Looking Glass、分布式探针或厂商提供的反向路由。

  5. 在晚高峰做 MTR

    建议 20:00–23:00 连续采样，观察终点 RTT、抖动和持续到终点的丢包。中间节点不回 ICMP 不等于转发丢包。

  6. 测单线程，也测多线程

    多线程跑满不能掩盖单连接质量差；远程操作和小文件传输常更接近单线程体验。

  7. 核对产品边界

    月流量、端口速率、共享比例、DDoS 清洗、路由故障时是否降级到普通线路，都比“精品”两个字更具体。

最低限度的合格证据：测试日期与时区、源城市与运营商、目标 IP、去/回程方向、AS Path 或 traceroute、晚高峰 MTR、单/多线程吞吐。缺少这些字段，结论只能算经验线索。

08 / DECISION

最后怎么选？让线路匹配你的损失函数

预算有限，主要下载或建站优先选靠近用户的普通线路，重点看晚高峰吞吐；联通用户在日本、美西常能找到性价比路线。
重视交互、远程办公优先低抖动和稳定回程。选择对应本地运营商的精品承载，通常比盲目购买更高配置有效。
服务三网公众用户选择真实多线 BGP 或三网分别优化的产品，并用三网探针验证；不要把单网精品当成三网精品。
大流量且能容忍偶发波动普通国际线路的大带宽更划算；可用 CDN、多节点、智能 DNS 或应用层容错改善体验。
业务中断成本很高不要只买“线路名”。需要多区域、多上游、可观测性和明确 SLA，必要时做主动故障切换。

一句话结论：机房位置决定物理下限，上游和 BGP 决定实际路径，互联容量决定高峰体验；精品网买的是更可控的路径，但只有与你的运营商、方向和时段匹配时才有价值。
